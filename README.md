# ScentScout

**Find your next favorite fragrance.**

[Try ScentScout](https://scent-scout.streamlit.app/)

ScentScout is an interactive fragrance recommendation app built with Python, Streamlit, and scikit-learn.

The application uses content-based filtering and cosine similarity to help users discover new perfumes based on fragrances they already love or their preferred scent notes.

### Features

- **Fragrance Twin:** Find perfumes with similar fragrance compositions.
- **Discover by Notes:** Choose up to five fragrance notes to discover personalized recommendations.
- **12,369 fragrances** across 463 standardized notes.
- **10 fragrance-family categories**, including Floral, Fruity, Gourmand, Spicy, and Woody.
- Four recommendations with similarity scores, ratings, and reference prices.
- Interactive, browser-based fragrance discovery.

### Original Machine Learning Project

ScentScout was developed from my original fragrance recommendation system, which includes exploratory data analysis, feature engineering, and content-based modeling using 24,063 fragrances.
